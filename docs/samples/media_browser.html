浏览器一律发送 Origin 请求头，服务端会按白名单校验。用 file:// 打开本页时 Origin 为 null，从本地 HTTP 服务打开则是 http://localhost:端口；两者都需要先在 ClassIsland 设置页加入「允许的 Origin」，否则握手会被 403 拒绝。
「声音」把远端机器的系统输出放到本机，仅在服务端于 server.hello 声明了 audio 能力时可用。它只能由点击开启——浏览器的自动播放策略要求 AudioContext 在用户手势里启动。开启后背景会随低频鼓点跳动， 歌词与进度也会整体后移一个抖动缓冲的深度，以对齐本机喇叭而非远端的实时位置。
